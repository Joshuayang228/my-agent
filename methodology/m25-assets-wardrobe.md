# 第一部分：认知框架

## 一、第一性原理：资产是过期后仍在的物身份；事件是会沉没的发生

朋友圈一条会滚出视野。若「灰帽衫」只活在某条动态文案里，下次无法指认同一件——连续性断了。
伙伴世界要求物**可指认**：同一 `assetId`，在动态、（将来）生图 prompt、对话提及里是同一个东西。

# 推论组 A：分层与隔离

## 二、三层寿命对照

| 层 | 寿命 | 例子 |
|----|------|------|
| Event | 发生记录，可沉 | 「傍晚发了条动态」 |
| Moment | 事件的可见投影 | 朋友圈那一行字 |
| **Asset** | 持久物 | 「灰色连帽衫」这件衣服 |

**判据**：删 moments → 灰帽衫还在；删灰帽衫 → 旧动态可降级无着装，**不该**用圈文案反推新建一件衣服。

## 三、「截面」一词不要用混

tech-spec / 模块卡常说朋友圈/衣柜是「截面」：

- 相对**朋友圈文案**：衣柜 UI 也是呈现层
- 相对**物本身**：`companion_assets` **就是物真相**

**判据**：说「衣柜是截面」时，若被理解成「可以没有 asset 表只靠文案」，表述失败——必须澄清。

## 四、按 roleId 隔离

每主角自己的柜；换 active = 换一整柜。
禁止跨角色共用一行 asset「凑合穿」——「这是谁的东西」是身份的一部分。

# 推论组 B：如何进入与被引用

## 五、获得路径

| 路径 | 现状 | 说明 |
|------|------|------|
| Starter 种子 | ✅ | 空柜幂等写入基础款，稳定 id |
| 显式 addAsset | ✅ API | 购买/剧情；可挂 source_event_id |
| 事件自动 grant | ✅ | M25-G2：publish 读 grantAsset；幂等 id |
| 用户编辑/删除 UI | ✅ | M25-G1：update/delete + AssetsPanel |

资产有 `acquired_at`；版本需求弱于 MUTABLE——物多为增删，不是全文演化。

## 六、事件引用，不拷贝物描述

```text
materialize moment 槽 → pickWardrobeAssetId → payload.assetId
projectMoment → getAsset(name) → 拼进 text
```

**禁止**：只把「穿着灰色连帽衫」写进 moment.text、不建 asset——不可指认。

## 七、引用断裂时降级，不伪造

资产已删：投影无着装后缀；**不**按文案自动 `addAsset` 补洞（那会制造幽灵柜）。

# 推论组 C：可见与扩展

## 八、仅 active 柜门打开

IPC `get-assets` / `AssetsPanel` 只暴露活跃主角。
非活跃柜在 DB，不因别人 tick 乱增（除非 Catch-up/显式逻辑触达该 role）。

## 九、kind 可扩展；衣柜 + 书架

`kind`：`wardrobe` / `bookshelf`（可再扩）。
W4 证明「引用 + 分桶 + 面板」；M25-G3 书架 starter + 面板分栏；**Assemble `## Bookshelf` + Moment「在读」**已接线（薄切片，勿编未入库书）。

## 十、叙事与生图预留

- **叙事（M30）**：模型不得宣称拥有未入库神装
- **生图**：payload（色/风格）预留拼 prompt；生图本身非本阶段（M24-G3）

# 第二部分：实战记录

## 做了什么（W4）

| 项 | 落点 |
|----|------|
| CRUD + starter | `life/assets.ts` |
| 挂引用 | `engine` + `pickWardrobeAssetId` |
| 投影读名 | `moments.ts` |
| IPC/UI | `get-assets` · AssetsPanel |

## 弯路与取舍

1. **先衣柜后万物**——闭环可演示再扩 kind。
2. **Starter 固定 id**（`wardrobe:{roleId}:{key}`）——防重复灌柜。
3. **grant 挂 publish、哈希不默认发**——剧情入口在 slot.grantAsset；防刷靠日上限 + 幂等 id。
4. **初稿补「截面」澄清**——减少和「无真相」的误读。

## 设计检查清单

1. 删 moments 后衣柜还在吗？
2. assetId 能否解析到稳定 name？
3. 非 active 资产是否出现在面板？
4. starter 是否幂等？
5. 是否存在「只写文案不建资产」的路径？
6. 模型是否声称未入库的神装？
