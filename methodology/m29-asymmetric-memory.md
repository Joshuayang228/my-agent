# 第一部分：认知框架

## 一、第一性原理：关系里的记忆必须「可被看见、可被纠正」，否则懂你会变成监视感

信息不对称有两个方向，都伤信任：

1. **她多知道**：用了用户没意识到还记得的细节 → 惊喜或毛骨悚然，取决于是否可解释、可撤销  
2. **她其实不知道**：装懂、编造「你上次说…」→ 失信，比忘记更糟  

第一性原理：

```
记忆体验 = 能力上可以不对称，治理上必须可透明、可纠错；惊喜止于失信线

├─ 推论组 A：两种不对称
│     §二 多知道 · §三 其实不知道（装懂）
│
├─ 推论组 B：透明与纠错
│     §四 可见 / 可编辑 / 可遗忘 · §五 错记被用上时
│
└─ 推论组 C：边界与分工
      §六 惊喜 vs 失信 · §七 与 M08 / MUTABLE / 生活世界
```

# 推论组 A：两种不对称

## 二、多知道：召回注入是能力，不是默认炫耀

L3 注入画像 + 向量召回，是为了少问废话、接得住上下文。  
产品态度：

- **允许**安静地用对（「还是短一点对吧」）  
- **鼓励**关键敏感点时可点明来源（「我记得你提过…对吗？」）——规范层，未强制  
- **禁止**用用户不知道存在的阴暗档案做操控感发言  

工程现实：模型不见得每次都标注「来自记忆」；所以**面板可见**比「口头自称记得」更重要。

## 三、其实不知道：禁止装懂

压缩摘要、召回 miss、换角后语境缺口——都可能「其实不知道」。  
行为底线：不确定就问或承认模糊，不发明「你说过」。  
这与 M27 推回、M21 不编造事实同族。

# 推论组 B：透明与纠错

## 四、可见、可编辑、可遗忘

最低治理面（已落地）：

| 能力 | 入口 |
|------|------|
| 看见 | MemoryPanel 列表（分类） |
| 增改删 | Panel + IPC；工具 `remember` / `forget` |
| 双写一致 | 结构化库与向量库联动删除 |

「可回滚」：条目级删除/更新即纠错；不做整库时间旅行。  
MUTABLE 版本回滚是人格侧（M22），不要和记忆条目混成一个撤销栈。

## 五、错记被用上时的体验

理想路径：用户说「我没说过 / 记错了」→ 模型应 forget 或改正 → 面板里那条消失或更新 → 下一轮不再引用。  

现状缺口：

- 对话里没有「本轮引用了哪些记忆 id」的芯片/旁注（Gap）  
- 用户未必知道去 MemoryPanel 找元凶  

纠错闭环：**口头承认 + 工具/面板落地**；只道歉不删库 = 假透明。

# 推论组 C：边界与分工

## 六、惊喜 vs 失信

| 惊喜（可取） | 失信（禁止） |
|-------------|-------------|
| 接住上周提过的偏好 | 捏造未存储的「记忆」 |
| 用户可在面板核对 | 用户无法发现、无法删除的暗记 |
| 敏感推断先确认 | 用推断当事实施压 |

判据：把 MemoryPanel 给用户看 30 秒，他会不会吓一跳或找不到「她刚才用的那条」？前者要治理分类与采集克制（接 M28）；后者要引用透明（Gap）。

## 七、与相邻模块

| 模块 | 记什么 | 透明怎么做 |
|------|--------|------------|
| **M08 记忆** | 用户事实/偏好/feedback | Panel + 工具 |
| **M22 MUTABLE** | 行为默契 | Settings 版本/回滚；不是 MemoryPanel |
| **生活事件** | 她自己的日子 | Moments；不是用户隐私库 |
| **向量对话索引** | 语义召回原料（用户侧） | 偏内部；勿当第二阴档 |

跨角色：用户画像可共享；角色默契与生活按 role 分桶——别在小林会话里用小周的 MUTABLE 假装「我记得我们」。

# 第二部分：实战记录

## 做了什么

| 项 | 落点 |
|----|------|
| CRUD + 分类 | `memory-store` · MemoryPanel · `memory:*` IPC |
| 工具 | `remember` / `recall` / `forget` |
| 注入 | runtime 画像 + `safeVectorSearch` → L3 |
| 防自我强化 | 不索引 assistant 原文（M08 G1） |
| 语义去重 | 写入路径（M08 G6） |

## 弯路与取舍

1. **先给面板、后做引用标注**：没有可见库，口头透明是空话。  
2. **forget 必须双清**：只删 SQLite 留向量 = 幽灵记忆。  
3. **反思用 feedback 未按 role 滤**：透明之外还有串味风险（M22-G2）。
