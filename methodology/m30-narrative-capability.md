# 第一部分：认知框架

## 一、第一性原理：故事感来自「可回调的同一条线」，能力感来自「不承诺做不到的事」

伙伴产品有两种翻车：

1. **叙事断裂**：压缩丢了关键关系节点、换角/Catch-up 对不上、朋友圈与嘴上说的日子打架 → 人不像同一个人  
2. **能力幻觉**：语气很能干，工具/权限/模型其实做不到 → 关系越亲，失望越大  

第一性原理：

```
体验可信 = 叙事不断线（同一条关系+世界）× 能力不掺水（预期可校准）

├─ 推论组 A：叙事连贯
│     §二 最小关系记忆 · §三 事实正确 ≠ 有故事 · §四 与压缩/世界接缝
│
└─ 推论组 B：能力边界
      §五 高估/低估 · §六 自然说「不擅长」 · §七 与透明/权限同族
```

# 推论组 A：叙事连贯

## 二、最小关系记忆：压缩时不可当废纸

长对话会 Snip/Compact（M07）。产品要求：

- **不可丢**：用户称呼偏好、进行中的共同约定、未完成的情感话题锚点（若已进结构化记忆/MUTABLE）  
- **可丢**：重复工具噪声、过期过程细节  

判据：压缩后她是否还知道「我们是谁、卡在哪」——不知道就只是新会话套皮。  
落地主要靠：记忆提炼进库、MUTABLE 默契、勿把关键关系只活在易被 Snip 的 tool 轮转述里。

## 三、事实正确 ≠ 有故事感

正确复述事实是底线；故事感来自：

- **回调**：提起上周的约定/玩笑（记忆或 Catch-up）  
- **里程碑**：第一次换角、第一次反思写入、重要项目并肩——目前无显式「里程碑对象」（Gap）  
- **世界截面一致**：嘴上、朋友圈、衣柜引用同一事件链（M23–M25）  

禁止：为了「像小说」编造未发生的日子或未入库的神装（接 M25/M29）。

## 四、与压缩 / 世界的接缝

| 来源 | 叙事作用 |
|------|----------|
| M07 压缩 | 保主线、丢噪声；摘要勿改写身份 |
| M08/M29 记忆 | 用户侧关系事实 |
| M22 MUTABLE | 相处默契口吻 |
| M23–M25 | 她自己的日子与物 |
| M26 名册 | 圈子关系短句，不串身份 |

召唤会话：对方叙事完整，但**不**推进其日子——故事是串门篇，不是偷改主线。

# 推论组 B：能力边界

## 五、高估与低估都有成本

| 偏差 | 用户感受 | 产品对策 |
|------|----------|----------|
| 高估 | 「你不是说能吗」 | L2 工具列表诚实；破坏性要确认；不会就说不会 |
| 低估 | 「怎么这么废，还配叫伙伴」 | 该用工具时用；plan-first 不等于懦弱 |

## 六、自然表达「我不擅长」

用主角语气承认边界，仍给下一步（查文档/换工具/要用户补信息）。  
aside 可心虚一句，主答必须给可行动路径（M27 两空间）。  
权限拒绝（M10）是硬边界；「模型不确定」是软边界——两者都不要演成万能。

## 七、与透明、权限同族

- **M29**：不知道就别装记得  
- **M10**：不能做的别绕过确认  
- **L2 Capabilities**：工具清单与 confirm 说明是能力边界的系统声明  
- **Eval B01**：语气像人，但不考核「假装无所不能」

随用户认知调预期：对方是新手时可多解释限制；老用户少废话——规范层，未做用户专家度模型（Gap）。

## 弯路与取舍

1. **先同源世界再谈故事**：没有事件/资产时「叙事」只能靠瞎编。  
2. **能力边界写进 L2 而非长 PROTECTED**：工具集会变，人设不该每次改圣经。  
3. **里程碑对象后置**：避免未想清就上成就系统。

## 自检问题

1. 压缩后关键约定还在吗？  
2. 朋友圈与对话日子是否打架？  
3. 有没有承诺做不到的工具能力？  
4. 拒绝时有没有仍像同一个人？
