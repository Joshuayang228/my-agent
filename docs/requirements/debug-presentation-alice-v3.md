## 背景（Why）

上一批已回流共享页头、短目录和正文优先结构，但用户仍反馈字号及信息呈现不协调。LLM 调用截图还显示重复标题、无关人物范围错误占据首屏、筛选溢出以及未读取被显示为零条和空列表。既有回流快照只证明当时完成的范围，不代表所有 Debug 页面已达到新的阅读标准。

问题需要结合各页实际任务、真实数据范围和状态逐项处理。前端 Skill 负责沉淀可复用的设计标准，本合同负责本次页面顺序、文件边界及施工证据，不把一次任务的推进方法变成长期规则。

## 技术方案（How）

### 参考与设计事实源

Alice 实际实现位于 `_reference/framework-harness/repos/alice-source/`：`styles/base/tokens.css` 提供语义文字阶梯，`styles/components/code-block.css` 提供技术内容阅读样式，`_extract/index-ppRSWnkN.js` 的 tM / sM 为提示词管理器与详情参考。其他页面进入施工时读取对应实现；没有对应业务时只比较最接近的阅读形态，不引入 Alice 专属能力。

本项目呈现规范以 `agent-skills/frontend-guidelines.md` 为执行依据，运行时数值和控件实现来自 `src/index.css`、Foundation 与设计注册表。字体比较同时记录 computed style、全局字号设置、字重、行高和平台回退；不把参考截图的像素尺寸当作 CSS 实值。

### 提示词管理器：已完成 P0 的保留范围

- P0 文件：`DebugPromptCandidate.tsx`、`DebugExperienceCandidate.tsx` 的 assets 分支、必要的隔离样式 / fixture 与对应测试；不能借候选修改正式组件默认或影响其他视角的共享 CSS。
- 生产落点：`DevPanel.tsx` 的 assets 页头与 `RegisteredAssetWorkbench.tsx`；数据仍来自 `debug:model-context-assets`、人物登记范围和 `assetUsageQuery`，不得复制生产资产正文到候选。
- 阅读顺序：一个页头、人物范围与搜索、短分组目录、选中正文；变量、完整标识、版本 / 指纹 / 来源与相关调用保留在关联的展开区。
- 检查重点：主要文字与小字的职责是否正确，目录与正文比例、条目行高、默认与选中边界、控件高度、长名称 / 长文、正文行宽及窄屏返回焦点。
- 状态覆盖：未读取、环境不可用、首次失败、刷新失败保留旧目录、成功空目录、搜索无匹配、选中资产缺失、来源与相关调用局部失败。没有成功读取时不显示零条结论。
- 如发现基础文字语义缺口，先用隔离故事说明影响与目标，再调整基础定义；不在 Debug 中建立第二套长期字号表，也不顺手调整其他页布局。

### 后续页面与已知问题

后续依导航顺序逐项检查，各页开始时补充实际参考、文件范围、真实数据来源和必测路径；未施工项不计为已完成。本次不复制新的导航清单作为事实源。

每页在本合同记录研究、候选实现、状态 / 排版验收和剩余问题。单页 P0 达标即可留存并转下一项；全部候选完成后再统一处理正式落点、共享 Foundation 定义和跨页回归。若多个页面暴露同一通用规范缺口，先验证其共性，再沉淀到前端 Skill；单页进度、施工顺序和回流安排只留在本合同。

LLM 调用的已知问题留到该页处理：壳与内部标题重复；全局调用页展示了无关人物范围错误；首次读取不可用时仍显示 `0 条 / 0 B` 和无匹配；默认技术筛选过多并横向溢出；错误与空态容器过大。整改需保留全部七种调用详情、懒读取、关联来源、导出及明确清空确认。

## 影响范围与明确不做

属于渲染层阅读结构和状态呈现调整，不改变 IPC、数据库、生产 Prompt、模型配置、权限或诊断动作的业务契约。缺少真实读取源时明确展示边界，不增加假能力。

不重新设计品牌字体、产品主侧栏、Settings 或人物世界；不因为 Alice 存在编辑和语言切换就加入这些功能。无新依赖。既有无关工作区改动不覆盖、不混入提交。

前端 Skill 仅更新从实际参考吸收的通用排版与呈现标准，不规定导航施工顺序、一次施工一个 Tab、下一页门槛或逐页批准。

## 实施与验收

1. 整理 Skill 为通用规范，并在本合同明确本次施工边界。
2. 从提示词管理器开始，按导航逐页检查真实代码与 Alice，记录问题、测量值和采用 / 不采用项。
3. 仅完善当前页 P0 候选。改一类问题后验证对应路径，再完成默认、失败、空态、长文本、深浅主题、窄宽与字号缩放检查；保留完整技术证据与真实操作边界。
4. 用内置浏览器验证当前候选，保存截图与关键交互证据；候选数据、接口契约替身与真实 Electron 读取分别解释。完成该页 P0 后提交推送并直接推进下一页，不逐页请求回流。
5. 全部导航项完成 P0 后，统一检查跨页一致性、共享基础定义、关联跳转及范围清单，向用户展示整批实际候选与剩余决策；在此时取得统一回流许可。
6. 按获准整批范围集中回流，正式页与故事格同步，验证真实查询、失败保留、关联跳转、焦点和诊断动作；更新模块卡及质量文档，通过自审、Unit、类型、构建、资产 / 文档门禁后提交推送。集中回流可组织为多个可独立回滚的提交，但不得交付缺失已批准页面的半成品。
7. 对照全部导航项、合同要求和实际生产证据完成最终审计；整批回流、验证、文档与推送均完成后才关闭完整目标并冻结合同。

## 风险与权衡

共享文字定义和字号缩放可能影响已采用页面，需要明确影响范围及相关回归。清理重复标题或折叠元数据不能损失完整证据、异常状态或操作入口。浏览器环境无 Electron 桥接时只能证明视觉与候选交互，不能宣称数据库读取通过。测试通过只证明覆盖的路径，不能替代实际视觉判断。

集中回流期间候选与正式页会暂时存在呈现差异；以明确标记、隔离样张和逐页证据说明状态，不提前将 P0 标为生产采用。末尾统一复核发现的问题返回对应候选修正，不以批量回流为由省略验收或默改批准范围。

- Alice tM 使用短分组目录与独立详情，分组文字为 13px；sM 的详情标题 15px，技术标识较小，正文有明确行高与独立阅读区。采用其文字职责和主从组织；自然语言正文沿用本项目 UI 字体，结构内容才使用等宽字形。不复制编辑、多语言或生产正文。
