## 背景与目标

旧 Debug 页面虽然引用 Foundation，但局部 CSS 强行覆盖按钮字号和颜色，搜索框再包边框；页头、计数、只读徽标和重复说明挤占首屏。浏览器预览没有 Electron 诊断接口，不能代替生产目录的数据验收。本轮视觉验收使用隔离候选，真实只读数据路径继续保留。

目标是用现有 Playground 页头与基础控件呈现相同的字体阶梯、边界和操作槽；默认看到标题、筛选、目录与正文，标识、版本、来源和能力边界按需展开。保留七组导航、全部证据和现有查询语义，不因简化丢失数据。

## 参考与技术方案

- Alice 提示词管理器的角色范围、搜索、分组目录和独立正文详情，以及领域阅读页的时间行、住所结构和旅行分组。仅借鉴阅读组织，不搬入语言切换、编辑和不存在的业务。
- 本项目 `PlaygroundPageHeader`、`TabStrip`、`ActionButton`、`TextField`、`Badge`、`EmptyState`、`ErrorState` 和 state-switchers 是基础事实源；不改这些组件的生产默认。
- P0 只修改 `src/components/playground/DebugExperienceCandidate.tsx`、`DebugPromptCandidate.tsx`、`DebugEvidenceCandidate.tsx`、`debug-experience.css`、`debug-evidence-fixtures.ts` 与对应测试、基础依赖登记、模块卡、账本、本文档和索引。候选 CSS 显式限定，正式 `DevPanel` 和共享 Debug CSS 不受影响。
- 移出默认展示的 key、分组与重复说明仍保留在「版本与来源」或「来源与诊断说明」。正文无额外背景卡，目录只显示短名称和必要类型。
- P1 经具体候选确认后同步 `DevPanel`、`RegisteredAssetWorkbench`、`CompanionEvidencePanel` 与 Debug 共享样式；Playground 来源路径、状态控制和夹具不得进入生产。

## 风险与边界

基础组件目前使用 11/12px 控件文字，本轮服从现有事实源，不以 Debug 局部放大代替基础设计决定。窄屏采用目录/详情切换，不能压缩成长行溢出。信息折叠不能隐藏失败状态、未读取状态或真正的异常。无新依赖，无 IPC、数据存储、模型、Prompt 或权限改动。无关工作区改动不纳入提交。
