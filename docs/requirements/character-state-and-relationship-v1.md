# 人物状态、关系与朋友圈策略施工合同 v1

> 状态：进行中
> 日期：2026-11-02

## 1. Why

Alice 的人物层不是孤立功能集合，而是由关系、情绪、位置、日程和生活事件组成的统一状态。现有 My Agent 已有关系阶段（陌生 / 熟悉 / 默契）和世界态中的心情、精力、社交需求，但关系没有持久化的事件依据，情绪没有情感日记与行为摘要，朋友圈也没有频率和可见性策略。

## 2. What

- 记录人物与用户的关系事件，形成可追溯的关系连续性；关系状态影响表达温度、称呼、主动程度和解释深度。
- 记录人物情绪事件并生成当前情绪摘要；情绪只影响表达、朋友圈基调和生活叙事，不影响任务执行、工具权限或事实判断。
- 朋友圈增加发布节奏、冷却时间和可见性策略。默认使用低频自然节奏；“三天可见”属于用户可配置的展示策略，不删除历史事实。
- 用户看到叙事化的心情与关系摘要；开发者 Debug 可看到结构化状态、来源和计算证据，产品界面不暴露可刷的 RPG 数值。

## 3. Alice 对照后的边界

- 稳定人格继续在 Role Pack；动态情绪、关系事件、位置和日程进入运行态。
- 情绪不能拒绝用户任务，不能改变权限，不能降低事实标准。
- 关系阶段不是单一分数。可以内部保留有界代理指标，但对用户呈现状态词和自然语言摘要。
- 朋友圈、日程、生图、对话都从同一当前状态读取，避免地点、活动和情绪互相穿帮。
- 朋友圈策略控制“是否生成 / 是否对用户展示”，不把未展示解释成没有发生。

## 4. How

新增人物状态域：

```text
companion_relationship_events
  relationship / sentiment / repair / milestone
companion_emotion_events
  trigger / valence / intensity / firstPersonNote / sourceEventId
companion_presence_policy
  postingCadence / cooldownHours / visibility / userConfigured
```

运行时每轮生成：

```text
稳定身份
→ 当前世界态
→ 关系阶段与近期关系摘要
→ 当前情绪摘要与表达指引
→ 朋友圈策略
→ 功能 Prompt 与输出协议
```

第一批完整范围：

1. 关系事件存储、读取、Debug 证据和主 Prompt 摘要；复用已有关系阶段，不另造一套阶段枚举。
2. 情绪事件存储与当前摘要；先支持确定性事件写入和结构化摘要，不阻塞主任务。
3. 朋友圈发布策略设置与读取；发布工具遵守冷却和可见性，用户显式发布仍可覆盖自动节奏。
4. 设置中的“伙伴与相处”增加关系 / 动态策略入口；人物世界展示当前可读摘要。

## 5. 验收

- 关系事件能从真实对话 / 生活事件进入存储，跨重启保留，人物切换隔离。
- 情绪事件能形成自然语言摘要并注入表达层；工具执行和权限决策不读取情绪结果。
- 同一状态下对话、朋友圈和生图读取相同地点 / 活动 / 情绪切片。
- 朋友圈频率、冷却和三天可见策略在正常、空态、失败、重启和跨人物场景下有测试。
- Debug 展示来源、时间、计算依据和策略；产品界面不显示“心情 65 / 好感 80”式属性栏。

## 6. 不做

本合同不做数值化好感度养成、不让情绪阻止任务、不建立独立朋友圈数据库、不自动把情感事件写进用户长期记忆、不实现复杂自主消费经济。情绪事件的模型提炼、每日完整 DayScript 和更复杂的主动行为在本批先保留清晰接口。

## 2026-11-03 发布策略扩展

为避免人物像机器人一样高频刷屏，朋友圈自动发布新增一层与提醒分离的策略：

2026-11-07：既有策略控件已从 Playground 候选回流正式「伙伴与相处」设置；设置保存继续复用真实 settings IPC，候选保留为隔离体验样张。

2026-11-07：关系事件历史补齐为独立 `companion_relationship_events` 表，按人物 / 来源生活事件幂等落库；当前关系快照继续用于 Prompt 和可见性计算，Debug 可读取近期事件依据。

- `companionMomentCadence`：手动、偶尔、按日程；只约束自动生活事件，用户明确发帖不受限。
- `companionMomentMaxPerDay`：自动发布每日上限，默认 3 条；达到上限后生活事件照常发生，朋友圈跳过本次分享。
- `companionMomentCooldownMinutes`：自动发布之间的最短间隔，默认 240 分钟；重要事件仍先进入同一队列，不绕过冷却。
- `companionMomentPostingQuietStart` / `companionMomentPostingQuietEnd`：自动发帖勿扰时段，默认 23:00–07:00；跨午夜按本地小时判断，用户明确发帖不受限。
- `companionMomentImagePolicy`：自动配图偏好，默认 `never`；当前支持关闭自动配图或仅附带事件已有图片，生图生成与预算闭环继续列入目标清单。手动生图与手动绑定动态保持原链路。

发布策略从最近已发布动态和当前本地日计算，不把提醒上限误当发帖上限；生活事件按原计划推进，自动分享按实际发帖时间计数。每次恢复最多分享最近一天内的一个片段，重复活动与地点会被去重。新增设置控件为 Playground 候选，待查看确认后回流。

## 2026-11-04 自动互动策略

朋友圈策略同时控制自动卡司互动，避免动态正文降低频率后评论仍然过密。

- `companionMomentInteractionPolicy`：关闭、偶尔、按动态；默认偶尔。
- 关闭时自动生活发布不生成卡司评论，用户手动评论、点赞和主角回复仍可用。
- 偶尔时只有关系变化或明确同框事件触发卡司互动。
- 按动态时沿现有关系表和公开名册选择评论者，失败回退为空互动。

该设置与发帖频率、提醒频率和主动问候分别计算，Debug 展示同一策略值。
