# 设置页头与间距统一 v1 施工合同

> 状态：已完成施工快照（2026-10-09）
> 生命周期：已完成施工快照（冻结）。用户确认 P0 并授权 P1，正式调用、验收与文档收口；当前能力以伙伴模块卡和质量文档为准。

## 背景（Why）

逐项检查 Playground 后再检查正式设置九个分区：主标题字号和字重基本一致，但外观、数据页与带眉题的页面不在同一高度；正式记忆页另加内边距。样张注入 settings 布局参数，正式页仍使用 fallback。共用组件不能代替跨页几何验收。

## P0 目标与边界（What）

- 本次完整交付为九个设置分区的 Playground P0 候选，不包含正式布局回流。
- 各分区共用一个页头：标题左对齐、同字号字重行高；标题后的说明使用统一样式，外观页也有简短业务说明，不用空白占位凑高度。
- 移除候选页头中的「设置样张」「伙伴设置」眉题及预览徽标；预览身份在独立实验区域显示，不挤占业务页头。
- 设置壳拥有页面外边距与内容宽度，页头到内容、内容区块间距引用现有 settings 布局参数，不新增数字规范。
- 业务模块只负责自身内容；嵌入时关闭其独立页头，避免双标题和重复内边距。
- 保留所有字段、状态样张、返回、主题切换、角色架、记忆与 Skill 详情交互。
- 不改正式 SettingsPanel、App、IPC、保存、权限、模型调用、数据或基础默认值；不把整个设置页面塞进 Foundation。

## P0 方案（How）

基础尺寸继续由 src/shared/content-layout.ts 和现有形态 / 字体 token 提供，SettingsPageHeader 是设置业务组合，不新增通用基础资产。

SettingsExperienceCandidate 集中组合分区页头与内容。AppearanceSettingsContent、CompanionSettingsContent、DataSettingsContent 增加显式 showHeader 能力，默认 true，只有 P0 调用关闭；About 已有同类能力。模型、记忆、权限、Skills、MCP 候选的重复页头由统一宿主接管，不删除业务内容。页头提供显式间距选项，仅候选引用共享参数，正式默认保持兼容。

不以全局 CSS 隐藏标题，不写覆盖所有 header 的选择器。实验状态切换与业务内容各自保持原有所有权，不读写真实设置。若角色架子页面自带详情标题，保留其导航语义，不强行将详情当成设置分区主页。

## 风险与权衡

- 不为视觉统一改变业务说明或删字段。短说明也可能在窄屏换行，首块纵坐标应按页头实际高度和统一间距计算，不要求所有内容绝对高度一致。
- 基础值与字体缩放共存，验收读取实际计算样式，不把缩放后的像素当成另一套 token。
- 不以固定高度或隐藏滚动来掩盖溢出；详情页、实验工具条与分区主页允许不同结构，但不能重复拥有页面外边距。
- 正式页已确认的差异属于待 P1 修正范围，P0 完成不能宣称正式设置已统一。
