# 伙伴设置时间控件与补充说明收口

> 状态：进行中；补充说明入口已按用户指令在 Playground 隐藏，时间控件方案待确认，正式回流尚未授权。

## 背景（Why）

伙伴设置的勿扰开始 / 结束使用裸数字输入，不易识别时间语义。用户要求先补 Foundation 控件，在 Playground 产品样张采用，再验收回流。相处补充说明入口拟移除，但现有 companionResponseNote 确实进入主对话 / 召唤的 L3 偏好区块，与记忆召回独立，不可宣称没有业务效果或擅自清空。

## 目标（What）

- 基础组件提供可复用时间选择器，默认态、禁用态和跨午夜组合可验收。
- Playground 伙伴设置使用该组件显示每日勿扰开始 / 结束；移除补充说明编辑块及重复伙伴标签。
- 选择器显示 24 小时制 HH:00，保持当前整点语义和 0–23 数据格式。
- 正式回流需用户查看候选后明确许可；既有偏好数据保留策略须明确，不进行隐式数据删除或迁移。

## 方案（How）

复用 Foundation SelectField 的原生选择与键盘能力组合 TimeSelect，不引入依赖，不另造浮层引擎。组件只接受和输出小时值，不负责保存或勿扰计算。独立组件 / 故事注册表登记身份、生命周期与故事，控件来源保持单一。

共享 CompanionSettingsContent 通过显式候选开关隐藏说明与范围标签，并注入时间控件；默认生产渲染不变。SettingsExperienceCandidate 使用本地隔离状态，不访问真实设置或 Prompt。

## 范围与归属

允许修改：Foundation 时间组件、FoundationAdvancedStories、ui-component-registry、foundation-story-registry、CompanionSettingsContent 的兼容候选接口、SettingsExperienceCandidate、相关 Unit / UI E2E 与本合同及文档索引、伙伴模块卡。

不修改：SettingsPanel 正式默认行为、IPC / preload / 共享设置类型、存储、Prompt、Runtime、通知调度、记忆 CRUD、已有未提交的无关改动。产品体验依赖登记如需修改，只添加当前控件依赖，不覆盖存量改动。

## 实施与验收

1. 确认整点时间选择与旧偏好数据边界。
2. Foundation 组件与故事同轮登记；验证选择、禁用、键盘、边界值和稳定尺寸。
3. Playground 设置采用；验证 22:00–08:00、同起止时段、提醒关闭 / 恢复、无补充说明及无重复标签。
4. 深浅主题和窄宽截图验收；Unit、类型检查、构建、资产和文档门禁通过后提交 P0 候选。
5. 用户确认具体候选及旧偏好策略后另行执行 P1，保留真实保存 / 失败重试、跨午夜和通知抑制契约。

## 风险与权衡

- 当前执行逻辑只支持整点，不展示可选分钟避免伪能力；分钟级需求须单独修改计算与存储契约。
- 删除编辑入口不等于停用已有偏好。P0 不触碰数据；P1 前须决定是否保留可管理入口、迁移或明确停用，不能留下用户无法管理而仍静默生效的配置。
- 日期选择器用于具体年月日，本次每日勿扰不采用日期控件，不扩大为通用日历建设。
