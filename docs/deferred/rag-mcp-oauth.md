## 留待研究的问题

RAG 本轮真实 SQLite / Vectra 红测已复现：两分块文档在第二块嵌入失败时仍返回成功，chunkCount 为 1。现有检索捕获服务错误后返回空数组，会混淆无匹配与服务不可用；这两个缺口尚未修复。后续须一起确认知识库是否需要独立入口、资料来源如何保存、何时建立与重建索引、用户如何感知失败，再恢复实现。

OAuth 后续需按用户实际连接的服务明确登录保持、退出、刷新和第三方互操作需求；已有本地协议与 Electron 测试不代表所有服务兼容。
