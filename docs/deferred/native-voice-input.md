# 原生语音输入 — 可行性评估（2026-08-03）

> wishlist：「原生语音输入」。本轮只做评估与暂缓落账，不交付不可用的 Mic 按钮。  
> 存放：`docs/deferred/`（非施工合同；曾误放 `docs/requirements/`，中间短暂用过 `docs/deferred/`）。

## 背景

- 曾用渲染进程 **Web Speech API**（`SpeechRecognition`）做中文连续识别；在 Electron 下不稳定（依赖系统/浏览器实现、权限与网络行为因平台而异）。
- 输入栏 Mic 已移除；**TTS 朗读**（`speechSynthesis`）仍可用，与 STT 无关。

## 候选方案

| 方案 | 优点 | 缺点 | 本轮结论 |
|------|------|------|----------|
| 恢复 Web Speech | 改动小 | 已踩坑；Win/Electron 可靠性差 | ❌ 不做 |
| 主进程调系统 STT（Win Runtime / SAPI） | 真·原生 | 需原生桥或额外依赖；Win/mac 分叉 | ⏸ 单独立项 |
| 云端 STT（Whisper / 厂商 API） | 质量稳 | 密钥、费用、隐私；非「原生」 | ⏸ 产品确认后可做 |
| 占位开关无实现 | 看起来有功能 | 违反「禁止假完成」 | ❌ 不做 |

## 暂缓条件（满足任一条再开做）

1. 选定一条路径（系统原生 **或** 云端 STT）并写清 Win 优先范围  
2. 有可测的最小验收：按住说话 → 文本进输入框 → 可发送  
3. 隐私说明（云端则必须明示上传音频）
