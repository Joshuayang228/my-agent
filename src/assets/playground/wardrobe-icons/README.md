# 衣柜图标对照素材

仅用于用户已批准的 Playground 图标选型，不是正式图标库。原图标仍为 Lucide；外部素材未安装运行依赖，也未回流。

| 分类 | Phosphor | IconPark |
|---|---|---|
| 套装 | coat-hanger（衣架） | clothes-suit（西服） |
| 上装 | t-shirt（T 恤） | clothes-short-sleeve（短袖） |
| 下装 | pants（长裤） | clothes-pants（长裤） |
| 外套 | hoodie（连帽衣） | clothes-windbreaker（风衣） |
| 鞋子 | sneaker（运动鞋） | boots（靴子） |

这些都是类别的代表性图形，衣架不代表整套穿搭结构，西服也不限制套装只能是西服。最终语义与 14px 可辨识性由用户对照后确认。

## 修改记录

路径及 viewBox 保留原作；IconPark 风衣的蓝色填充改为 none，形成单色轮廓。页面通过 CSS alpha mask 使用素材并继承当前文字色，避免深浅主题出现固定黑色或白色底。未增加外部 URL、脚本或字体请求。
